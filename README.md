## Лабораторная работа №1 (CV, вариант на 3)

### Горюнов Даниил М8О-408б-22

### Соответствие требованиям задания

В `AI_LAB1/labCV.ipynb` выполнено:

- выбор и обоснование [датасета дорожных знаков/автомобилей](<https://www.kaggle.com/datasets/pkdarabi/cardetection>);
- выбор метрик `Precision`, `Recall`, `mAP@50`, `mAP@50:95`, `F1`;
- обучение бейзлайна (`YOLOv8n`) и его оценка;
- формулировка и проверка гипотез улучшения (аугментации, `Cosine LR`, изменение конфигурации обучения);
- обучение улучшенного бейзлайна и сравнение с базовым;
- самостоятельная имплементация детектора на PyTorch;
- добавление в собственную модель техник из улучшенного бейзлайна и повторная оценка;
- итоговые выводы по каждому этапу.

### Быстрый запуск ЛР1

1. Установить Python 3.10+.
3. Установить зависимости:

```bash
pip install ultralytics torch torchvision opencv-python matplotlib seaborn pandas scikit-learn jupyter
```

4. Открыть ноутбук:

```bash
jupyter notebook AI_LAB1/labCV.ipynb
```

5. Последовательно выполнить ячейки.

> Примечание: в ноутбуке путь к `data.yaml` задан абсолютным путем (`data_config = ...`). При запуске на другой машине замените его на актуальный локальный путь к датасету.
